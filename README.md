<details>
<summary><img src="assets/card-pptx-to-video.svg" width="96%" alt="pptx-to-video: turns a PowerPoint into an animated MP4, plus a local deck AI"></summary>

Reads a `.pptx` file (shapes, pictures, tables, charts, theme colours, layouts), gives every element an entrance animation that fits what it is, renders the frames in headless Chrome and encodes them with ffmpeg. It has 14 video styles, camera zooms, slide transitions, output up to 4K, and narration read from the speaker notes.

It ships with **Quoro AI**, which runs fully offline. A decision-tree model trained on a generated dataset classifies every slide element, a SQLite database stores ingested decks, and a checker flags placeholder text, TODOs, typos and leaked keys before you export.

[Source](https://github.com/JohnThrisokaran000/pptx-to-video)
</details>

<details>
<summary><img src="assets/card-hk.svg" width="96%" alt="hk: a local LLM runtime written from scratch in Zig"></summary>

A runtime and model format for local language models, written in Zig. It loads models with zero-copy mmap and has CPU, CUDA and Vulkan engines and an OpenAI-compatible server. It also supports 2:4 sparsity, Net2Net model growth, version history kept inside the model file, and self-learning loops.

[Source](https://github.com/JohnThrisokaran000/hk)
</details>

<details>
<summary><img src="assets/card-patchwork.svg" width="96%" alt="PatchWork: hotfixes live websites without a rebuild"></summary>

Patches live websites without rebuilding them. A patch is a small file written in a DSL. PatchWork re-anchors it when the site changes, verifies it in a real browser and releases it through a reverse proxy. It rolls the patch back automatically when visitors' browsers start reporting errors. Built for the GDG on Campus CRCE college round.

[Source](https://github.com/JohnThrisokaran000/Shotgun_college_round)
</details>

<details>
<summary><img src="assets/card-sentinel.svg" width="96%" alt="Sentinel: a confidential wellbeing platform for armed forces personnel"></summary>

A confidential early-support platform for uniformed-service personnel. It has regular check-ins, daily journaling by text or voice, an AI companion, configurable risk monitoring, audited access to sensitive records and an admin console. The front end is Next.js. Behind it are a FastAPI service and PostgreSQL and Redis, run with Docker Compose.

[Source](https://github.com/JohnThrisokaran000/mentalhealthfinal)
</details>

<details>
<summary><img src="assets/card-ciphervault.svg" width="96%" alt="CipherVault: encrypts text and images in the browser"></summary>

A Flask site for encrypting and decrypting text in the browser. It also turns an image into an encrypted `.png` plus a `.meta` file needed to restore it.

[Source](https://github.com/JohnThrisokaran000/Cipher_Vault)
</details>

<details>
<summary><img src="assets/card-volunteer.svg" width="96%" alt="Volunteer Check-in: tracks NGO volunteer hours with geotagged proof"></summary>

Volunteers apply, wait for an admin to approve them, and get their login details by email. They check in with the date, location, hours and geotagged photos. Admins review the proof on a map, and the volunteer is emailed a receipt or a decline notice.

[Source](https://github.com/JohnThrisokaran000/cep-registration)
</details>
